Section 1
About Realtor

Realtor is India's transparent real estate discovery platform built specifically for the Hyderabad market. The platform addresses a critical gap in the Indian property market: the lack of price transparency, verified data, and accessible analytics for everyday buyers and NRI investors.

Unlike traditional real estate portals, Realtor publishes both the government circle rate and the prevailing market rate side by side, along with RERA registration status, developer credibility scores, site verification reports, and AI-powered property analysis — all in one place.

🎯 Our Mission
To eliminate information asymmetry in Indian real estate by providing buyers with the same level of data that institutional investors have access to — verified, accurate, and up-to-date.
📍 Current Coverage
Hyderabad, Telangana — covering 17+ micro-markets including Gachibowli, HITEC City, Banjara Hills, Jubilee Hills, Kondapur, Kokapet, Financial District and more.

Section 3
Getting Started

3.1 Installing the App

The Realtor app is available as an Android APK. Download and install it directly on your Android device — no Play Store required.

1
Download the APK
Obtain the Realtor APK file from your administrator or the official download link. The file name will be Realtor-v1.0.2.apk.
2
Enable Unknown Sources
On your Android device go to Settings → Security → Install Unknown Apps and enable installation from your file manager or browser.
3
Install & Open
Tap the downloaded APK file, accept permissions, and tap Install. The Realtor icon will appear on your home screen.
⚠️
Requires Android 8.0 (API level 26) or above. A stable internet connection is required for all features including property listing, map, and AI chat.

3.2 Creating an Account

1
Open the App
The app opens to the Sign In / Sign Up screen. Tap Sign Up tab to create a new account.
2
Enter Your Details
Fill in your First Name, Last Name, Email Address, and a secure Password. All fields are required.
3
Agree & Create Account
Check the Terms & Privacy Policy checkbox and tap Create Account. You'll be logged in immediately.

3.3 Logging In

If you already have an account, tap Log In tab on the auth screen, enter your registered email and password, and tap Sign In. Your session persists — you won't need to log in again unless you explicitly sign out.

✅
Your login token is stored securely using Expo SecureStore — an encrypted device-level storage. Your credentials are never stored in plain text.

Home Screen & Property Listings

The Home Screen is the central hub of the Realtor app. It loads all publicly listed properties from the server and displays them as browsable cards.

4.1 Screen Layout

Top Area
Contains the search bar and filter button. Fixed at the top of the screen — always visible even while scrolling through listings.
Property Cards
Each card shows: property photo carousel, title, area, price per sqft, total price in ₹ Lakhs/Crores, status badge, demand label, size, beds/baths, and a like (❤️) button.
Bottom Navigation Bar
Five tabs: Home (listings), Map (map view), Explore (investor dashboard), Saved (liked properties), and Profile.

4.2 Property Cards Explained

4.3 Liking a Property

Tap the ❤️ icon on any property card to save it to your favourites. The icon turns red when saved. You must be logged in — the app will prompt you to sign in if not authenticated. Your liked properties sync to the server and are accessible from any device.

Section 5
Search & Filters

5.1 Search Bar

The search bar at the top of the Home Screen lets you find properties by typing any keyword. The search is instant — results update as you type. You can search by:

  • Area name — e.g. "Gachibowli", "HITEC City", "Banjara Hills"
  • Property title — e.g. "Prestige", "Cloud Nine", "Metro"
  • Property type — e.g. "Villa", "Apartment", "Office"
  • Plot ID — e.g. "HYD-001", "HYD-012"

To clear the search, tap the ✕ icon that appears on the right side of the search bar.

5.2 Filter Panel

Tap the Filter button (sliders icon) next to the search bar to open the full-width filter panel. The filter panel has three sections:

📍 Location Filter (Primary)
A horizontal scrollable row of area chips — one for each unique area in the current listings. Tap any area chip (e.g. "Gachibowli", "Kokapet") to show only properties in that area. Tap All to clear the location filter. The count in brackets shows how many listings exist in each area.
🏠 Type Filter
Two checkboxes — Residential and Commercial. You can select one, both, or neither (= all types shown). Selecting only "Commercial" shows offices, retail spaces and warehouses. Selecting only "Residential" shows apartments, villas, duplexes etc.
✅ Verified Only Toggle
A toggle switch that, when turned on, filters to show only properties that have been site-verified by the Realtor team. Verified properties have confirmed RERA numbers, cross-checked documents, and a transparency score of 70+.
💡
The filter badge on the Filter button shows a red dot with a count when filters are active, so you always know how many filters are currently applied.

5.3 Clear Filters

Open the filter panel and tap Clear all (top right of the filter panel) to reset all filters at once and return to the full listing view.

Section 6
Property Details

Tap View Details on any property card to open the full property detail screen. This screen provides comprehensive information about a single property.

6.1 Image Carousel

The top section shows a swipeable photo gallery with up to 5 property images. Swipe left or right to browse photos. The dot indicators below show how many photos are available and which one is currently displayed.

6.2 Property Information Sections

SectionInformation Shown
Header Property title, area, status badge, demand label, RERA number (if available), verified badge

6.3 Transparency Score

Each property has a Transparency Score from 0–100 calculated from: RERA registration (30 pts), Dual rate disclosure (25 pts), Site verification (25 pts), Source attribution (20 pts). A score above 70 is considered highly transparent.

🛡️
Properties with a ✓ Verified badge have been physically site-visited by the Realtor team and all listed documents have been cross-checked with the Sub-Registrar office records.

Section 7
Interactive Map View

The Map View tab shows all properties as price pins on a live Google Map of Hyderabad. This gives you an instant spatial understanding of property distribution and pricing across the city.

7.1 Reading the Map

⬜ White Pin
Inactive property marker. Shows price per sqft (e.g. ₹7,200). White background with red text.
🔴 Red Pin
Selected/active property marker. Shows price per sqft in white text on red background. Slightly larger than inactive pins.

7.2 Interacting with the Map

1
Tap a Price Pin
Tap any price pin to select it. A property card slides up from the bottom showing the property photo, title, area, price, status and demand.
2
View the Property Card
The card at the bottom shows key property info. Tap View Details on the card to go to the full property detail screen.
3
Dismiss the Card
Tap anywhere on the map (away from a pin) to dismiss the property card and deselect the current pin.
4
Navigate the Map
Pinch to zoom in/out. Drag to pan. The map defaults to Hyderabad centre. Your current location is shown with a blue dot if location permission is granted.
⚠️
Location permission is optional. If denied, the map still works fully — it just won't show your current location dot. All properties will still appear as pins.

Sections 8 & 9
Saved Properties & Visit Scheduling

8. Saved Properties

The Saved tab (heart icon in bottom navigation) shows all properties you have liked. This list is tied to your account and persists across sessions and devices.

How to Save a Property

Tap the ❤️ icon on any property card on the Home Screen or the ❤️ button on the detail screen. The icon turns red to confirm it's saved. The count on the Saved tab badge updates immediately.

How to Remove a Saved Property

Tap the ❤️ icon again (it turns grey/outline) to un-save it. Or open the Saved tab and tap the heart icon on any saved card to remove it.

ℹ️
If you are not logged in and try to save a property, the app will redirect you to the Sign In screen. Your saves are stored server-side — they sync automatically after login.

9. Schedule a Site Visit

You can book a site visit for any available property directly from the property detail screen.

1
Open the Property Detail Screen
Tap View Details on any property card to open the full detail screen.
2
Tap "Schedule Visit"
Scroll to the agent section and tap the Schedule Visit button. A visit booking sheet slides up from the bottom.
3
Fill in the Visit Details
Enter your preferred visit date (calendar picker), preferred time (e.g. "10:00 AM"), your name, and an optional message for the agent.
4
Submit the Request
Tap Confirm Visit. Your request is sent to the admin portal where it appears as "Pending" until confirmed by the team.
✅
Once your visit is confirmed by the admin team, the status changes to Confirmed. Contact the listed agent directly if you need to reschedule.

Section 11
Investor Dashboard

The Explore tab (compass icon in the bottom navigation) opens the Investor Dashboard — a dedicated view designed for NRI investors and serious buyers who need market-level data, not just individual listings.

11.1 Transparency Overview

A summary tile row showing across all listed properties:

MetricDescription
VerifiedTotal number of site-verified properties
With RERAProperties with a valid RERA registration number
Dual RateProperties disclosing both circle rate and market rate
UnverifiedProperties awaiting verification
Avg Market PremiumAverage % by which market rate exceeds government circle rate

11.2 Top Zones by ROI

A ranked list of Hyderabad areas sorted by average year-over-year price appreciation. Each zone shows the average market rate per sqft and the number of listings. Use this to identify which micro-markets are delivering the best returns.

11.3 Top ROI Properties

The top 4 individual properties with the highest year-over-year gain percentage. Each card shows property name, area, current price, and ROI %. Tap any card to open the full property detail screen.

💡
ROI % is calculated as: (Past Year Gain ÷ Current Price) × 100. This represents the annualised price appreciation for the last 12 months, not a guaranteed future return.

Section 14
Managing Properties

14.1 Properties Table

Navigate to Properties in the sidebar. The table shows all listings (public and private) with columns for: Plot ID, Title, Area, Category, Status, Verified, RERA Number, Price/sqft, Size, Visibility, Approval Status, Last Updated, and Actions.

Searching & Filtering

  • Use the search bar to filter by plot ID, title, area, or status
  • Check Verified only to show only verified listings
  • Click the refresh button (↺) to reload data from the server

14.2 Adding a New Property

Click Add Property in the sidebar or the + Add Property button on the Properties page. The form has 4 steps:

1
Basic Information
Enter Plot ID (e.g. HYD-101), title, area name (free-text field — type any Hyderabad locality), and select the property category (Residential / Commercial / Villa / Apartment etc.)
2
Pricing
Enter price per sq.ft and plot size. The system automatically calculates the total price. Add historical price entries for each year (2020–2025) using the + Add Year button.
3
Details & Location
Fill in agent info, description, POC transparency fields (circle rate, market rate, RERA number, developer, flood risk). Use the map search bar to find the location — type the area name and click Search. Then fine-tune by clicking the exact spot on the map.
4
Review & Publish
Review all details in the summary view. Toggle Visible to public to control whether the listing appears in the mobile app. Click Publish Property.

14.3 Editing a Property

Click the ✏️ edit icon on any row in the properties table. A drawer slides in from the right with all editable fields. Make your changes and click Save Changes. The drawer also allows you to:

  • Toggle the property between Public (visible in app) and Private
  • Add or remove price history entries
  • Upload site photo URLs
  • Add local updates (news/events affecting the property)
  • Submit a verification report after a physical site visit

14.4 Deleting a Property

Click the 🗑️ delete icon on any row. A confirmation dialog appears — click OK to permanently delete the listing. This action cannot be undone.

⚠️
Deletion is permanent. All associated price history, site photos, and verification reports for that property will also be deleted. Consider setting the status to Draft instead of deleting if you may need the data later.

The CSV Bulk Upload feature allows you to add up to hundreds of properties at once by uploading a structured spreadsheet file. This is the fastest way to populate the platform.

15.1 How to Upload

1

Click Properties in the sidebar.
2
Click Upload CSV

Troubleshooting
Problem Likely Cause Solution
App shows blank/no properties Backend API is in cold start (free tier sleeps after inactivity) Wait 30–60 seconds and pull-to-refresh. The server is waking up from sleep.
Map is grey / not loading Google Maps API key not set in the native build Rebuild the APK via EAS Build with the API key in app.json.
Map pins not visible SVG rendering issue on Android Google Maps Rebuild the APK — the latest build fixes this with flat-colour markers.
Cannot log in (mobile) API backend is unreachable or credentials are wrong Check internet connection. Verify email/password. Try again after 30s.
Save / like button not working Not logged in Log in to your account first — saved properties require authentication.
AI Chat not responding OpenAI API key expired or rate-limited Check admin environment variables. Rotate the OpenAI API key if needed.

Admin portal shows blank page Not logged in or session expired Navigate to the root URL — you'll be redirected to login automatically.
Admin map shows no markers REACT_APP_GOOGLE_MAPS_KEY not set in Render environment Add the Google Maps key to Render Static Site → Environment → trigger a redeploy.

Section 21
Technical Information

21.1 System Architecture

📱 Mobile App
Built with React Native + Expo SDK 54. Uses Expo Router for file-based navigation. Fonts: Manrope family (400–700). Maps: react-native-maps with Google Maps. Secure storage: expo-secure-store.
🖥️ Admin Portal
Built with Create React App (React 18). Maps: @react-google-maps/api. Icons: react-icons/fi. Deployed as a static site on Render.
🔌 Backend API
Node.js + Express REST API on port 3011. Authentication via JWT (7-day expiry). CSV parsing: csv-parse. File uploads: multer. Deployed on Render Web Service.
🗄️ Database
PostgreSQL 17 hosted on Neon (serverless). 9 tables: properties, mobile_users, admin_users, price_history, user_saved_properties, visit_requests, chat_history, developers, verification_reports.
